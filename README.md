# 自販機マネジャー

オリジナルドリンクを開発して自販機を経営する、放置型の経営シミュレーションゲームです。
スマートフォン向けの Web アプリ（PWA）で、ホーム画面に追加してアプリのように遊べます。

## 遊べること

- ドリンクの開発（容器・味・ラベルの柄や文字・透明ボトルなど）
- 仕入れ、自販機への補充、並べ替え、価格設定
- 設置場所の解放、自販機の購入（色も選べる）、設備の強化
- 天気・季節・イベントで変わる売れ行き、放置中の売上
- BGM と効果音（Web Audio で合成）

## 公開方法（GitHub Pages）

1. このフォルダの中身をリポジトリのルートに置いて push します。
2. GitHub のリポジトリで Settings → Pages を開きます。
3. Source を「Deploy from a branch」、Branch を `main` / `/(root)` にして保存します。
4. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で開けます。

ビルドは不要です（素の HTML / CSS / JavaScript のみ）。

## スマートフォンへのインストール

- iPhone：Safari で開き、共有ボタン →「ホーム画面に追加」
- Android：Chrome で開き、メニュー →「アプリをインストール」

## セーブデータ

- GitHub Pages で遊ぶ場合、セーブは端末のブラウザ内（localStorage）に保存されます。
  端末を変えるときは、設定 → バックアップの「コピー」と「復元」で移せます。
- claude.ai のアーティファクトとして開いたときだけ、クラウド保存が使われます。

## 通知について

アプリを開いている間・裏にある間は、売り切れなどを端末に通知できます。
アプリを完全に閉じている間に通知を届けるには、販売をサーバーで計算してプッシュ通知を
送る仕組み（例：Firebase Cloud Messaging）が別途必要です。受け取る側（`sw.js` の push）は実装済みです。

## 更新するとき

ファイルを変えて公開するときは、次の2つを上げてください。

- `version.json` の `version`：遊んでいる人の画面上部に「アップデートがあります」が出て、タップで更新されます
- `sw.js` の `VERSION`：古いキャッシュが入れ替わります

## 構成

```
index.html            画面の土台
manifest.webmanifest  PWA の設定
sw.js                 Service Worker（キャッシュ・通知）
css/style.css         見た目
icons/                アプリアイコン
js/config.js          バランス調整の数値（ここだけ触れば難易度を変えられる）
js/state.js           ゲームの状態とセーブデータの移行
js/sim.js             販売シミュレーション
js/events.js          天気・イベント
js/audio.js           BGM・効果音
js/render/            自販機・ドリンク・街並み・マップの描画（SVG）
js/views/             各画面
```
